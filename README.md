# Portfolio — TEKO Folly Hariel Marcel

Site portfolio statique (Astro 7) : accueil, case studies, labo interactif (15 modules).

**Live :** [hxriell.github.io/portfolio](https://hxriell.github.io/portfolio/)

## Stack

- Astro 7 · HTML · CSS · JavaScript
- GitHub Pages (déploiement via GitHub Actions)

## Développement local

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Structure

| Route | Contenu |
|-------|---------|
| `/` | Accueil, profil, services, projets, formation |
| `/lab` | Laboratoire interactif |
| `/projects/[slug]` | Études de cas |
